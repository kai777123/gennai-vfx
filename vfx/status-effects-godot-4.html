Put burn, freeze, shock, poison and petrify on any mesh in Godot 4

Updated 2026-11-16. Tested on Godot 4.4.1 and 4.7.2, Forward+ and Compatibility.

Burning, freezing, shock, poison and petrify can crawl over a mesh from the point of impact in Godot 4. With NOXALUX you call Noxalux.afflict($Enemy, Noxalux.Kind.BURN, hit_point, 4.0), and the effect spreads out from the hit for four seconds. If you want more control, add a NoxaluxStatus3D to the MeshInstance3D. apply() starts an effect or stacks it up to three times, and cleanse() removes one kind or all of them. The status stays on the mesh, which means a walking character carries it along. Effects also react to each other: a freeze bolt into a fire makes steam and puts it out. The pack has 50 presets in 3D and 2D for Godot 4.4 and newer, with no textures. The code is below, plus a demo that runs in the page.

The code

Noxalux.afflict($Enemy, Noxalux.Kind.BURN, hit_point, 4.0)     # from the hit point, for four seconds
var status := NoxaluxStatus3D.new()
$Enemy/Body.add_child(status)                                # a MeshInstance3D
status.apply(Noxalux.Kind.SHOCK, hit_point, 5.0, 2)           # crawls out from the hit; 2 = a second stack
status.cleanse(Noxalux.Kind.ALL)                              # or one kind, or let it expire

Stacks go from 1 to 3. The ticked signal reports the kind and the stack count on each tick, and the health you take off is up to you.

Try it in your browser

It loads the pack's own demo, about 12 MB the first time, and it opens on scene 2 of 11, “Five attributes”. Left and right arrow keys, or the on-screen buttons, move to other scenes. A desktop browser works best; the first start can take up to a minute while the shaders compile.
