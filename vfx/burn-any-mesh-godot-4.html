Burn any mesh in Godot 4

Updated 2026-11-16. Tested on Godot 4.4.1 and 4.7.2, Forward+ and Compatibility.

If you want a crate, a barrel or a character to catch fire in Godot 4, you don't have to park a particle emitter on top of it. Add a PyroluxBurn3D node under the MeshInstance3D and call ignite() with the hit position. The fire starts at that point and spreads across the surface. It chars whatever it covers, and it can burn the object away, with a burned_out signal when it's finished. I built it to work on any mesh you give it. It's part of PYROLUX, which has 49 fire, explosion, smoke and lava presets for Godot 4.4 and newer. It makes its look in code and needs no texture files, and it runs in a Web export. Read the code below, then press the button to run the demo right here.

The code

$Crate/PyroluxBurn3D.ignite(hit.position)          # fire spreads over the mesh from the hit point
$Crate/PyroluxBurn3D.burned_out.connect(_on_crate_burned)
Pyrolux.wind = Vector3(2, 0, 0)                    # flames, smoke and embers lean with it

PyroluxBurn3D sits under the MeshInstance3D you want to burn. The wind line is global: every flame, smoke column and ember in the scene leans the same way.

Try it in your browser

It loads the pack's own demo, about 8 MB the first time, and it opens on scene 11 of 15, “Set anything on fire”. Left and right arrow keys, or the on-screen buttons, move to other scenes. A desktop browser works best; the first start can take up to a minute while the shaders compile.

What is in the pack

The pack also has campfires, torches, walls of fire, explosions, smoke, sparks, lava, a flamethrower and a meteor strike, in 3D with a 2D side-view set and a pixel-art mode. I made the hit position the only thing you have to pass in.
